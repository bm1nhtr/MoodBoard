# Mood Board Collaboratif

Mur de post-it numériques pour partager des pensées et humeurs. MVP frontend avec données mock.

## Lancer le projet

### Frontend (MVP actuel)

L’application tourne sans backend : les posts sont simulés en mémoire.

```bash
cd full-stack-app/frontend
npm install
npm run dev
```

Ouvre [http://localhost:5173](http://localhost:5173) dans le navigateur.

**Autres commandes :**

- `npm run build` — build de production
- `npm run preview` — prévisualiser le build
- `npm run lint` — linter le code

### Backend (optionnel)

Pour utiliser l’API users existante plus tard :

```bash
cd full-stack-app/backend
npm install
npm run dev
```

Le serveur écoute sur [http://localhost:3000](http://localhost:3000).
